# Product Overview — Demoblaze

## Mô tả sản phẩm
Demoblaze (PRODUCT STORE) là trang web demo e-commerce, cho phép người dùng:
- Xem danh sách sản phẩm (Phones, Laptops, Monitors)
- Đăng ký tài khoản mới (Sign up)
- Đăng nhập (Log in)
- Thêm sản phẩm vào giỏ hàng (Add to cart)
- Đặt hàng (Place order)
- Liên hệ (Contact)
- Xem thông tin (About us)

## Đối tượng người dùng
- Khách hàng muốn mua sản phẩm điện tử
- QA/Tester muốn học và thực hành automation test

## Tính năng chính

| Feature | Mô tả |
|---------|-------|
| **Signup** | Đăng ký tài khoản mới với username + password |
| **Login** | Đăng nhập bằng username + password |
| **Product Listing** | Xem danh sách sản phẩm theo category (Phones, Laptops, Monitors) |
| **Product Detail** | Xem chi tiết sản phẩm, giá, mô tả |
| **Cart** | Quản lý giỏ hàng (thêm, xóa sản phẩm) |
| **Place Order** | Đặt hàng với thông tin thanh toán |
| **Contact** | Gửi tin nhắn liên hệ |

## Giao diện chính
- Header: Logo, Home, Contact, About us, Cart, Log in, Sign up
- Body: Carousel, Category menu, Product grid
- Footer: About Us, Get in Touch, Powered by
